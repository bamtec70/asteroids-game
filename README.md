# ASTEROIDS — 1979 Arcade Classic

A browser tribute to the 1979 vector arcade game. Every line is drawn on an HTML5 canvas and every sound is synthesized with the Web Audio API — no ROMs, images or audio files.

Play: https://bamtec70.github.io/asteroids-game/

## Controls
| Key | Action |
|---|---|
| Left/Right or A/D | Rotate |
| Up or W | Thrust |
| Space | Fire (max 4 shots) / Start |
| Shift (or Down/S) | Hyperspace |
| P / Esc | Pause |
| M | Mute |

Phones get on-screen rotate, thrust, fire and hyperspace buttons.

## Features
3 rock sizes (20/50/100), big (200) and small aiming (990) saucers, wraparound, hyperspace, extra ship every 10,000, vector font, the two-tone heartbeat that speeds up as the wave goes on, high score saved in localStorage.
